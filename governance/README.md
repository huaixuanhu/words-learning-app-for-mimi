# 项目治理入口

本目录覆盖整个 Mimi Vocabulary 项目。结构与权威文件位置以 [contract.json](contract.json) 为准；长期边界由根目录 `AGENTS.md` 管理。

开始任务时先读取 AGENTS、本入口、contract 和匹配的当前计划，仅按本次问题展开相关来源。当前保存恢复、Mimi 精确归档及项目内本机备份目录由 V2.3 计划 Stage 2.3.15 持有；月度 R2 与凭据整理入口仍为 Stage 2.3.13。旧发布和失败回执保留其原有证据含义。

实质变更结束前，同步受影响的计划、架构、决策、Changelog 和 AI log，检查验证结果及授权边界。运行 `npm run governance:check` 和适合本次变更的定向测试；结构检查不能代替语义审查或授予远端操作权限。

当前规则适配 `human-ai-governance v0.8.4`；费用说明及 Codex / Claude Code 协作规则统一由 `AGENTS.md` 管理，`CLAUDE.md` 仅引用该入口。每条新 AI log 写明执行工具及已知模型，区分自查与实际发生的独立核验；本轮证据不代表 Claude Code 新会话已实际加载。

保留现有结构检查、项目专用预检和设计主文档。两份日志按新条目在前排列，预检选取第一个以 `## YYYY-MM-DD` 开头的条目；字段要求仍由项目预检维护。v0.8.1 至 v0.8.4 的适配依据及保留边界见本目录决策索引。后续开发从本入口及匹配的产品计划继续，本次治理维护不启动新的产品开发阶段。
