# 项目治理入口

开始任务时先读取 AGENTS、本入口、contract 和匹配的当前计划，仅按本次问题展开相关来源。当前备份与凭据整理入口是 V2.3 计划 Stage 2.3.13；旧发布和失败回执保留其原有证据含义。

实质变更结束前，同步受影响的计划、架构、决策、Changelog 和 AI log，检查验证结果及授权边界。运行 `npm run governance:check` 和适合本次变更的定向测试；结构检查不能代替语义审查或授予远端操作权限。
